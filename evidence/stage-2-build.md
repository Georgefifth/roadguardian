## 2. 产品审查与发现的问题优先级

在梳理用户真实遭遇车祸后的 15 分钟认知隧道状态时，我们识别出以下核心问题并按严重度排列：

1. **P0 级致命安全漏洞：现场人员在高速路面逗留导致二次撞击**
   - *现状*: 许多应用直接让用户下车对着车辆划痕拍照。
   - *危害*: 美国 NHTSA 数据显示每年大量公路死亡发生在事故发生后的车道逗留二次碰撞。
   - *解决*: 将“人身安全避险”置于 Stage 1 绝对优先地位，强制红字大号警示：“严禁站在车尾或两车之间！所有人必须立刻撤离至钢制护栏后方”。
2. **P0 级财产诈骗风险：黑拖车敲诈（Bandit Towing Extortion）**
   - *现状*: 事故后不法黑拖车监听警用电台在 3-5 分钟内抵达，逼迫惊魂未定的受害人在空白账单上签字，事后索要 $1,500+ 天价赎车费。
   - *解决*: 专门设计“防黑拖车防御盾（Tow Shield）”，提供核验问题与“绝不签署空白工单”电子防身卡。
3. **P1 级法律责任陷阱：口头道歉被反咬自认全责**
   - *现状*: 多数司机出于礼貌下意识说“对不起/我刚才没看清”，被对方记录为承认全责的口供证据。
   - *解决*: 设计“中立陈述盾”，提供只陈述方向、天气、车流的中立事实模板，杜绝道歉类主观词汇。
4. **P1 级证据遗漏与防伪纠纷**
   - *解决*: 6 大标准证据槽位（车牌、VIN 挡风玻璃码、驾照、保单、碰撞点全景、路口标线），并计算本地 SHA-256 完整性哈希。

## 3. 已完成的技术与 UX 契约优化

1. **UX 契约落地与设计 Tokens**:
   - 严格按照 `design/UX.md` 规范构建：黑曜石深色背景（`#0B0F17`，夜间不眩目且极度省电）、警示琥珀金（`#F59E0B`）、致命危险绯红（`#EF4444`）、安全翠绿（`#10B981`）。
   - 首屏通过“如果换到任何其他 SaaS 都不违和就重做”测试：高对比度四阶段 HUD、911 紧急大字直拨、坐标大字朗读栏、二次事故护栏站位警示、黑拖车防诈卡，任何普通 SaaS 都不具备这一高辨识度视觉与功能。
2. **离线优先与零依赖架构**:
   - 纯客户端运行（React 19 + TypeScript + Tailwind CSS + Lucide Icons + Vite 6）。
   - 所有的照片数据、地理位置、当事人信息存储于本地 LocalStorage / IndexedDB 中，0 网络延迟，0 云端隐私外泄。
3. **内置实战演练模式 (Practice Drill Mode)**:
   - 一键载入真实拟真事故情境（“US-101 追尾碰撞实战案例”），包含完整的坐标、6 项证据照片、对方 Marcus Vance 驾照保单与防黑拖车核验证明，方便评委与测试人员在 3 秒内体验全部 4 阶段功能。
4. **状态处理与交互容错**:
   - 彻底解决异步 GPS 获取时的状态竞争 Bug（通过 functional state updater 保证演练数据不被旧 GPS 请求覆盖）。
   - 移动端 390px 深度适配，底部 Sticky 操作栏高度 ≥ 52px，大拇指单手可达，无水平滚动条。

## 5. 尚未解决的限制与诚实说明

1. **真实摄像头权限受限于用户浏览器授权**: 如果用户完全禁用了浏览器的摄像头权限，RoadGuardian 自动降级为文件上传选择器与手动输入，并在演练模式下提供“模拟采样”兜底，不阻断核心流程。
2. **GPS 精度受制于设备硬件与遮挡**: 在隧道或高架桥下 GPS 可能存在偏差，界面明确提示输入最近的高速出口或里程桩标号（Mile Marker）。
3. **法律效力边界**: 界面与文档中明确声明该中立陈述与取证卷宗为用户自述证据备忘录，不替代交警官方交通事故认定书。
